A travel poster for LUMARIS, a floating salt-lagoon city that does not exist — drawn entirely in pure Python (standard library only), with a hand-authored bitmap typeface.

## Run it

```sh
python3 main.py
```

This writes the poster to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
